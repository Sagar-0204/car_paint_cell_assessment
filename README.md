# Robotic Car Painting Cell — MuJoCo Simulation

**Name :** Vidya Sagar Tirandas

**Software :** MuJoCo (with Python)

**Robot used :** 6-axis industrial robot (ABB IRB 6700 class) mounted upside-down on a 2-axis overhead gantry, with a rotary-bell spray gun

## How to run

```bash
pip install -r requirements.txt
python view_simulation.py
```

To re-plan the painting program from scratch: `python plan_program.py`
